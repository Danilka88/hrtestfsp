перечень используемых библиотек с точными версиями генерируется из них для

## 4. Внешние зависимости — за интерфейсами (mock-first)

| Интерфейс | Реальная реализация | Mock-реализация (по умолчанию) |
|---|---|---|
| `LLMProvider` | GigaChat REST API | Детерминированные шаблоны/rule-based |
| `FspProvider` | Реестр ФСП (после хакатона) | Синтетические достижения из seed |
| `EmailProvider` | SMTP | Логирование в консоль/файл |
| `StorageProvider` | S3/MinIO | Локальный том |
| `ProctorProvider` | Внешний прокторинг | Заглушка (флаг «не подключено») |

**Правило:** любая внешняя зависимость имеет mock-реализацию, поэтому демо
воспроизводимо оффлайн и не зависит от доступности сторонних сервисов.
