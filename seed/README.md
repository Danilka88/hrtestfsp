# Демонстрационные данные

Сам скрипт наполнения: [`backend/scripts/seed_demo.py`](../backend/scripts/seed_demo.py).
Полный сброс стенда к демонстрационному состоянию: `bash scripts/reset-demo.sh`.

Этот каталог — пояснение к данным, а не место для скриптов: наполнение живёт рядом
с моделями, которые оно создаёт, и запускается из контейнера API.

## Что создаётся

| Сущность | Сколько | Зачем в демонстрации |
|---|---|---|
| Кандидаты | 8 | профили с подтверждённым грейдом; один — **без истории ФСП** |
| Работодатели | 2 | две компании с потребностями |
| Сессии тестирования | по каждому кандидату | подтверждённый грейд, а не самоописание |
| Приглашения | 5 | механика «работодатель выходит первым», разные статусы |
| Вакансии | 3 | вторая механика: кандидат откликается сам |
| Отклики | 2 | решение работодателя по отклику |
| Короткие задания | 2 | регулярная поддержка профиля (общее и по специализации) |

Демонстрационный сценарий воспроизводится оффлайн, без внешних сервисов: если
локальная модель недоступна, ИИ-слой отдаёт демо-ответ и помечает его источник.

Демонстрационные доступы печатает `make demo` (или `bash scripts/reset-demo.sh`).
