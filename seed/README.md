# Демонстрационные данные

Каталог для seed-скриптов: синтетические кандидаты, работодатели, вакансии,
приглашения и достижения участников (в том числе профиль **без истории ФСП**).

Демонстрационный сценарий должен воспроизводиться оффлайн, без внешних сервисов.

Реализуется на Этапе 7 (`docs/03-mvp-plan.md`).
